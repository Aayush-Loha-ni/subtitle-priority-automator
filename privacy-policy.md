# Privacy Policy

**Subtitle Priority Automator** does not collect, store, transmit, or share any personal data.

## What data does the extension handle?
- **Language preferences** — stored locally using `chrome.storage.sync`, synchronized only across your own Chrome browsers where you are signed in. No data leaves your device.
- **Streaming site URLs** — read only to detect which platform you are on (e.g., YouTube, Netflix) so the extension can find and select the right subtitle element. This information is processed in-memory and never stored or transmitted.

## Third-party services
The extension contains no analytics, no trackers, and no third-party SDKs. The "Support on Ko-fi" button opens a link to ko-fi.com if clicked — no data is sent automatically.

## Data sharing
We do not sell, rent, or share any user data with anyone.

## Changes
If this policy changes, the updated version will be posted here and reflected in the extension's store listing.

## Contact
For questions, open an issue on the project's GitHub repository or contact the developer via the Chrome Web Store support channel.
